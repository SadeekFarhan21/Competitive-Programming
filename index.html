macOS bootstrap

Code contest ready.

Set up the complete competitive-programming workspace on a fresh Mac—compiler, formatter, font, snippets, extensions, and repository included.

Download setup 
/bin/bash -c "$(/usr/bin/curl -fsSL https://raw.githubusercontent.com/SadeekFarhan21/Competitive-Programming/main/setup.sh)"
  • Clones the repository
  • Installs GCC and Boost
  • Installs Orion Browser
  • Installs OpenAI Codex
  • Configures clangd
  • Restores VSCodium
  • Installs Geist Mono
  • Loads your snippets

Review scripts before running them. Apple may show one Command Line Tools installer dialog.
